# 产业链卡点评分

一句话：**输入一个产业链/热点/事件，输出一份能点开看依据的评分报告。先排层级，再排公司，每一分都有出处。**

## 何时用

- 用户丢来一个板块、产品、技术路线或新闻事件，想知道"这条链上该先看谁"
- 用户手上有几只候选股，要按"卡脖子程度"排研究顺序
- 用户想验证某家公司是不是真的卡在关键环节

不需要用的场景：只要一段结论文字、只要单家公司财务分析、只问某个指标怎么算——直接回答，别套报告。

## 输入

用户给一句话就够：`CPO 光模块` / `HBM` / `AI 电源` / `固态电池 干法电极` / `某厂断供事件`。

缺信息按默认推进，不要卡住：
- 未指定市场 → 默认 A 股科技与先进制造；用全球客户与竞争格局解释 A 股公司
- 主题过宽（如"AI"）→ 收窄到最有卡点的 2–3 个子环节，并在报告 `verdict` 里说明收窄理由
- 用户自带权重 → 覆盖默认 rubric，权重必须加总 100

## 执行流程

### 第 1 步：拆层级（必须先做完）

把链条拆成 3–5 层（上游 / 中游 / 下游），逐层回答一个问题：**如果这一层明天断供，下游多久能恢复？**

据此给 0–10 的卡点强度，按分数从高到低排。口径见 [五维评分规则](references/scoring-rubric.md) 的"第 0 步"。

层级只判断环节本身，不看公司：不涉及谁在做、谁份额高、谁收入大。这一步没做完就选股票，等于跳过研究直接给答案。

### 第 2 步：选标的（3–5 只）

在卡点层级里找公司，**至少覆盖两个不同层级**，只覆盖一层的说明层级分析没落地。

每家公司必须说清：卖什么、卖给谁、处在哪个商业阶段。研发 / 送样 / 认证 / 小批量 / 量产 / 订单 / 确认收入，七个阶段不能混。

证据用 [证据阶梯](references/evidence-ladder.md) 判断强弱，来源路径见 [市场来源手册](references/market-source-playbook.md)，研究步骤见 [研究流程](references/deep-research-workflow.md)。

**每条证据都要能点回原文**：写 `d`（日期）、`src`（来源名），并尽量补 `url`（公告/新闻/互动易原链接）与 `page`（页码或问答编号）。页面上来源名会渲染成可点击的 `↗` 外链，没有链接的证据只算半个证据。

### 第 3 步：五维打分

| 维度 | 权重 | 判什么 |
|---|---:|---|
| 卡脖子强度 | 30 | 明天断供，下游多久能恢复 |
| 下游覆盖 | 25 | 服务多少个正在花钱的终端 |
| 竞争格局 | 20 | 供给端有没有纪律 |
| 预期差 | 15 | 和共识差在哪一件可验证的事 |
| 壁垒议价 | 10 | 卡点能不能变成毛利和现金流 |

**纪律**
1. 先写证据再给分，禁止先定分数再找理由
2. 分差 ≥3 必须能说出"差在哪一件事实"
3. 同一主题内同一把尺子；跨主题分数不可比
4. 缺证据记 0 并标 `[MISSING]`，不代为估算
5. 封顶必须执行并在页面显示"原始 → 封顶 + 原因"：
   - 卡脖子强度 ≤10 → 封顶 55
   - 下游覆盖 ≤8 → 封顶 65
   - 预期差 ≤5 且竞争格局 ≤10 → 封顶 60
6. 定级：≥80 **S 核心研究** / 65–79 **A 重点跟踪** / 50–64 **B 观察名单** / <50 **C 暂缓**

### 第 4 步：写得分明细（这一步不能省）

每个维度都要写清：**分数带、计入得分的事实、未计满的原因、判定依据、为什么停在这一档**。

```js
SCORE_NOTES["300308.SZ"]["卡脖子强度"] = {
  band: "27–30 档",
  plus: ["事实 1", "事实 2"],
  minus: ["差在哪"],
  basis: "2026 半年报（8/28）……",
  verd: "给 27 不给 30：……"
}
```

`verd` 是最重要的一句：必须解释"为什么不是上一档，也不是下一档"。没有这句，分数就是拍的。

### 第 5 步：填模板交付

复制 [报告模板](assets/report-template.html)，只替换三个对象：`const REPORT = {...}`、`const SCORE_NOTES = {...}`、`const FIN = {...}`，其余不动。

**`FIN` 是财务口径表**，排在层级排序之后、标的列表之前，11 列固定：标的 / 层级 / 综合分 / 收盘价 / 市值(亿) / PE(TTM) / 营收 YoY / 净利 YoY / 毛利率 / 毛利率变动 / 现金流÷净利。每个入榜标的都要有一条，缺的写 `"—"`，不估算。同时填 `meta.finPeriod`（报告期）与 `meta.priceDate`（取价日）。

财务是验证不是打分：分数已在五维里定了，这张表用来暴露矛盾——高分但营收负增长、净利靠非经常性收益（现金流÷净利 <0.6）、毛利率下滑却给高分。发现矛盾要么在 `insight` 解释，要么下调对应维度，不许两张表各说各话。

字段、版面、视觉规范见 [HTML 报告输出规范](references/html-report-spec.md)。

## 输出长什么样

```
主题概览：名称 · 一句话结论 · 标的数 / A级以上 / 最高分 ·（右上：示例徽标 / 复制结论 / 研究日）
产业链层级排序：3–5 层，卡点强度 0–10，优先研究 / 跟踪 / 观察 / 不优先
优先研究标的财务口径：11 列表格，按综合分排序，窄屏横向滚动
┌ 左：标的榜（按综合分降序）        ┬ 右：选中标的详情 ────────────┐
│ 01 中际旭创 84 ▓▓▓▓▓▓▓▓░░        │ 分数环 + 定级                  │
│ 02 天孚通信 80 ▓▓▓▓▓▓▓░░░        │ 五维卡片（可点击展开得分明细）  │
│ 03 新易盛   76 ▓▓▓▓▓▓░░░░        │ 核心洞察                       │
│ ...                               │ 产业链位置 ｜ 排序理由          │
│                                   │ 证据链（带日期 + 来源链接）     │
│                                   │ 主要风险 / 失效条件             │
│                                   │ 关键观察位 / 数据缺口           │
└───────────────────────────────────┴───────────────────────────────┘
```

**没有搜索框**：报告是一次运行的静态快照，页面里放搜索框无处可查，不要加。切换主题靠主题概览的 chips。

视觉：Apple 液态玻璃，`backdrop-filter: blur(26px) saturate(200%)` + 双层高光描边 + 22px 圆角 + 环境光渐变。四种降级必须齐全（减弱动效 / 降低透明度 / 深色 / 高对比）。

## 交付话术

给三句话，不要长篇复述报告：
1. 文件路径
2. 层级卡在哪一层、先研究哪一家、为什么
3. 最大的未解问题（`gaps` 里最关键那条）

## 边界

- 每个数字可追溯，否则标 `[MISSING]`；超过 90 天标 `[STALE]`
- 检索不到 ≠ 不存在，区分"已查来源未见"与"不存在"
- 关键观察位写的是估值锚与失效位，不是买卖点，不给仓位建议
- 分数是研究排序，不是预期收益；报告页脚固定"本报告仅供研究参考，不构成个人投资建议"
- 涉及内幕信息一律拒绝
