# 五维卡点评分规则 v1.0

用于把"产业链卡点"研究结论转成可比的 0–100 分，**唯一目的是排序下一步该研究谁**，不是预期收益，也不是买卖信号。

## 第 0 步：先给层级打分（0–10）

在给公司打分之前，先给**产业链层级**打一个 0–10 的卡点强度，用来决定"先看哪一层"。它和下面 30 分制的「卡脖子强度」同源，区别是**只看环节，不看公司**——不涉及谁在做、谁份额高、谁收入大。

| 分值 | 判定标准（只看环节本身） |
|---:|---|
| 9–10 | 全球可替代供应商 ≤2 家；下游切换需重新认证 ≥12 个月；断供会直接停线或改设计 |
| 7–8 | 可替代 3–5 家，但产能/良率受限；认证 6–12 个月；短期扩不出来 |
| 5–6 | 多家可选，切换成本中等；卡在产能而非技术 |
| 3–4 | 充分竞争，切换 <3 个月；主要是组装、集成或通用件 |
| 1–2 | 无技术门槛，纯贸易或代工环节 |

层级排序的常见错误：
- 把"离需求最近"当成"最卡"——下游客户离需求最近，但议价权在客户手里
- 把"最上游"当成"最卡"——上游材料若有多家可替，一样不卡
- 层级卡但公司不卡——这一层只有 2 家能做，但那 2 家不是 A 股标的，此时应在报告里写明，而不是硬套一家公司上去

## 总分结构

| 维度     |      权重 | 一句话内核                  |
| ------ | ------: | ---------------------- |
| 卡脖子强度  |      30 | 如果这个环节明天断供，下游多久能恢复？    |
| 下游覆盖   |      25 | 这项卡点服务多少个正在花钱的终端？      |
| 竞争格局   |      20 | 供给端的纪律性够不够，价格会不会被打穿？   |
| 预期差    |      15 | 我们的判断和市场共识差在哪一件可验证的事实？ |
| 壁垒议价   |      10 | 卡点能不能变成毛利率和现金流？        |
| **合计** | **100** |                        |

打分顺序固定：**先写证据，再给分**。禁止先定分数再找理由。

---

## 1. 卡脖子强度（30）

判断材料，按顺序找：

1. 全球/国内可替代供应商数量（点名，不要只写"少数几家"）
2. 下游切换供应商需要多久（认证周期、重新流片/送样、产线改造）
3. 产能集中度（CR3 全球份额）与扩产周期（设备交期多长）
4. 断供后的实际后果（停线、降规、改设计）
5. 是否存在替代技术路线（能绕过就不算硬卡点）

| 分数带   | 判定标准                                         |
| ----- | -------------------------------------------- |
| 27–30 | 可替代供应商 ≤2 家；切换需重新认证 ≥12 个月；国产近乎唯一；下游存在实质停线风险 |
| 22–26 | 可替代 3–5 家，但产能/良率受限；认证 6–12 个月；短期扩不出来         |
| 15–21 | 多家可选，切换成本中等；卡在产能而非技术                         |
| 8–14  | 充分竞争，切换 <3 个月                                |
| 0–7   | 通用件，或纯组装/贸易环节，无卡点                            |

> 反作弊：仅有"国内领先""打破垄断""市占率第一"这类表述，不算证据，最高给 21 分。必须有具体的供应集中度、认证周期或断供后果。

## 2. 下游覆盖（25）

要算两个东西：**下游个数 × 每个下游的资本开支方向**。

| 分数带   | 判定标准                                                    |
| ----- | ------------------------------------------------------- |
| 23–25 | ≥3 个独立下游同时扩产（如 AI 数据中心 + 车载 + 消费电子），或单一超大体量下游处于明确资本开支上行 |
| 18–22 | 1–2 个下游，其中至少一个是上行周期                                     |
| 12–17 | 单一下游、需求平稳，或单机价值量过低（占 BOM <2%）                           |
| 5–11  | 下游萎缩，或技术路线可能被替代                                         |
| 0–4   | 需求依赖补贴、单一客户或一次性项目                                       |

> 加分项：单机用量 × 单价能被算出来，且客户结构分散。若客户集中度 >50% 且是同一客户，按下一档处理。

## 3. 竞争格局（20）

| 分数带   | 判定标准                        |
| ----- | --------------------------- |
| 17–20 | CR3 >70%，价格稳定或上行，扩产受设备/资质约束 |
| 13–16 | CR3 50–70%，格局清晰但存在 1–2 家挑战者 |
| 8–12  | 分散，正在价格竞争，扩产周期短             |
| 3–7   | 严重过剩，行业性亏损                  |
| 0–2   | 出清中，看不到拐点                   |

> 关键动作：把**行业已公告的总扩产量**和**需求增速**放在一起算。只看公司自己的扩产计划会严重高估格局。

## 4. 预期差（15）

| 分数带   | 判定标准                                             |
| ----- | ------------------------------------------------ |
| 13–15 | 有明确、可验证、与共识相反的事实（订单已签未披露、市场误判技术路线、被错误归类），且卖方覆盖稀薄 |
| 9–12  | 故事市场知道，但低估了量级或时点                                 |
| 5–8   | 共识方向正确，只是节奏差异                                    |
| 2–4   | 已被充分定价，覆盖密集                                      |
| 0–1   | 纯题材，没有基本面锚                                       |

> **硬约束**：说不出"哪一件事实"的预期差，最高 6 分。"我觉得市场没看懂"不是预期差。

## 5. 壁垒议价（10）

| 分数带  | 判定标准                                              |
| ---- | ------------------------------------------------- |
| 9–10 | 毛利率连续 4 个季度提升或维持高位；有涨价/预付款案例；认证粘性强；经营现金流/净利润 >0.8 |
| 7–8  | 毛利率稳定，议价中性                                        |
| 4–6  | 毛利率承压，被大客户压价                                      |
| 0–3  | 代工属性，无议价权，应收账款高企                                  |

> 数据优先看序列（至少 4 个季度），不看单期。合同负债、预收款是议价权的领先指标。

## 总分定级

|     总分 | 级别         | 含义                     |
| -----: | ---------- | ---------------------- |
| 80–100 | **S 核心研究** | 优先投入研究时间，下一步验证具体数据     |
|  65–79 | **A 重点跟踪** | 值得持续跟踪，存在一个待解决的商业/财务问题 |
|  50–64 | **B 观察名单** | 逻辑成立但证据或经济性不足          |
|    <50 | **C 暂缓**   | 现阶段不投入研究时间             |

## 修正规则（封顶，必须执行）

| 触发条件              | 处理                           |
| ----------------- | ---------------------------- |
| 卡脖子强度 ≤10         | 总分封顶 **55**（不是卡点，故事再好也不优先）   |
| 下游覆盖 ≤8           | 总分封顶 **65**                  |
| 预期差 ≤5 且 竞争格局 ≤10 | 总分封顶 **60**（已定价的拥挤赛道）        |
| 任一维度缺证据           | 该项记 0，标注 `[MISSING]`，并在报告中列出 |
| 证据全部缺失            | 不给总分，只列研究问题                  |

封顶后必须在报告中显示"原始分 → 封顶后分数"和触发原因，不允许静默改分。

## 打分纪律

1. **同一主题内必须是同一把尺子**。横截面分差 ≥3 分要能说出"差在哪一件事实"。
2. **跨主题的分数不可直接比较**。不同主题的"30 分卡脖子"不是一个量级。
3. **分数是研究排序，不是预期收益**。S 级不等于会涨，C 级不等于会跌。
4. **未知 ≠ 差**。缺证据是研究缺口，不是商业质量差，报告里要写清楚是哪一种。
5. **技术进展分阶段**：研发 / 送样 / 认证 / 小批量 / 量产 / 订单 / 确认收入。把"送样"当"量产"是最常见的扣分来源。
